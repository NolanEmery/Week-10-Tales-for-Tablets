# Week-10-Tales-for-Tablets
Plan It:

What is the goal of this website?

To be a comic app where each page contains text and an image that gets animated into a video when the user first navigates to the page.

Who are you building for, and what do they care about?

The audience is kids who like to see stuff move and want to be entertained.

Describe how a child should use the storybook from the moment they visit the site. What should they see first, what should they click, and what should happen next?

The user can click on either side of the screen to navigate between pages. Can also include sound and visual effects for when the user clicks between pages.

How should each page of Johnny Builds to Mars feel interactive, like a pop-up book or small game?

Clicking between pages and sound effects.

How should the site look and feel for young children?

Make the app colourful.

Test It:

Include more pages. Make the story progress slower.

Expand It:

Add drawing to page 2. Interactivity to get to next slide (for example, tap rocket). Rocket triggers a screen shake. Make the slide take up the full page.
